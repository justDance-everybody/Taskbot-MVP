# 飞书任务管理Bot - 用户使用指南

## 📱 快速开始

### 第一步：添加Bot到群聊
1. 在飞书中创建一个群聊（或使用现有群聊）
2. 点击群设置 → 群机器人
3. 添加「任务管理Bot」

### 第二步：测试连接
在群里发送：
```
ping
```

Bot会回复：
```
pong! 🏓 Bot is alive!
```

---

## 🎯 核心功能使用

### 1. 创建任务

#### 方式1：使用命令（推荐）
```
/newtask
```

Bot会引导你填写：
1. **任务标题**：例如 "开发用户登录功能"
2. **任务描述**：详细说明任务要求
3. **所需技能**：例如 "Python, FastAPI, JWT"
4. **截止时间**：格式 YYYY-MM-DD
5. **紧急程度**：low/normal/high/urgent

#### 示例对话
```
你: /newtask

Bot: 请提供任务标题：
你: 开发用户登录功能

Bot: 请提供任务描述：
你: 实现用户登录功能，支持邮箱和手机号登录，使用JWT认证

Bot: 请提供所需技能（用逗号分隔）：
你: Python, FastAPI, JWT

Bot: 请提供截止时间（格式：YYYY-MM-DD）：
你: 2026-01-20

Bot: 请提供紧急程度（low/normal/high/urgent）：
你: high

Bot: ✅ 任务已创建！
     任务ID: TASK001
     
     正在匹配候选人...
```

---

### 2. 候选人匹配（自动）

任务创建后，Bot会自动推荐Top-2候选人：

```
Bot: 推荐候选人：

1. 张三 (92分)
   - 职级: 高级
   - 经验: 5年
   - 技能匹配: Python ✓, FastAPI ✓, JWT ✓
   - 理由: 技能完全匹配，经验丰富

2. 李四 (85分)
   - 职级: 中级
   - 经验: 3年
   - 技能匹配: Python ✓, FastAPI ✓
   - 理由: 技能基本匹配，有相关经验

请回复数字选择候选人，或回复"取消"
```

---

### 3. 选择候选人并指派

回复数字选择：
```
你: 1
```

Bot会：
1. ✅ 创建任务专属子群
2. ✅ 邀请你和承接人加入
3. ✅ 发送任务通知

```
Bot: ✅ 已选择候选人：张三
     
     正在创建任务子群...
     
Bot: ✅ 任务子群创建成功！
     
     📋 子群信息：
     - 群名称: T-TASK001-开发用户登录功能
     - 成员: HR（你）+ 张三 + Bot
     
     📱 你会收到群邀请通知，请点击加入
```

     ✅ 代码审查通过

## 📊 自动功能

### 1. 进度提醒
任务周期过半时，Bot会自动提醒：

```
Bot: ⏰ 任务提醒
     @张三 任务"开发用户登录功能"已过半，请注意进度
     
     当前状态: in_progress
     剩余时间: 3天
     请及时完成任务
```

### 2. 每日报告
每天自动生成统计报告：

```
Bot: 📊 每日任务报告 (2026-01-20)

总任务数: 15
已完成: 8 (53.3%)
进行中: 5
待处理: 2

今日完成: 2个任务
平均评分: 90分

紧急任务: 1个
需要关注: TASK001 (即将到期)
```

任务完成7天后自动归档：

```
Bot: 📦 任务已完成7天，即将归档本群
     群名称将更新为：[ARCHIVED] T-TASK001-开发用户登录功能
     Bot将退出群聊
     
     感谢大家的配合！👋
```

## 💡 使用技巧

### 技巧1：快速创建任务
准备好任务信息，一次性填写完整，避免中断。

### 技巧2：详细的任务描述
任务描述越详细，AI匹配的候选人越准确。

### 技巧3：准确的技能标签
使用标准的技能名称，例如：
- ✅ Python, FastAPI, PostgreSQL
- ❌ python, fast api, postgres

### 技巧4：及时更新进度
在子群中随时更新进度，方便HR跟踪。

### 技巧5：使用GitHub链接
提交任务时附上GitHub PR链接，Bot会自动检查CI状态。

## ⚠️ 注意事项

### 1. 权限要求
- HR可以创建任务和选择候选人
- 承接人可以提交任务
- 所有人可以查看信息

### 2. 任务状态
- **pending** - 待处理
- **assigned** - 已指派
- **in_progress** - 进行中
- **submitted** - 已提交
- **completed** - 已完成
- **returned** - 需返工

### 3. 简历格式
- 支持PDF格式
- 文本PDF效果最好
- 扫描版PDF需要OCR支持

### 4. 子群管理
- 每个任务有独立子群
- 完成后7天自动归档
- 归档后群名称会加上 [ARCHIVED]

## 🆘 遇到问题？

### Bot没有回复
1. 检查Bot是否在群里
2. 检查服务是否运行
3. 查看日志：`tail -f app.log`

### 候选人匹配不准确
1. 检查任务描述是否详细
2. 检查技能标签是否准确
3. 更新候选人信息

### 简历解析失败
1. 确保PDF是文本格式（非扫描件）
2. 检查文件大小（<10MB）
3. 手动在多维表格中补充信息

### 子群没有创建
1. 检查Bot权限配置
2. 确保候选人user_id正确
3. 查看服务日志
