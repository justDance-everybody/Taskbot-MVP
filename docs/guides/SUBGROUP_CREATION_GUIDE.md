# 子群创建功能说明

## 概述

当HR选择候选人后，Bot会**自动创建一个任务专属子群**，用于任务的全程沟通和跟进。

---

## 子群创建流程

### 1. 任务创建阶段
```
HR在主群: /newtask
Bot: 请提供任务信息...
[HR填写任务详情]
```

### 2. 候选人匹配阶段
```
Bot: ✅ 任务已创建！正在匹配候选人...

推荐候选人：
1. 张三 (90分) - 技能匹配度高，具备Python和FastAPI经验
2. 李四 (85分) - 经验丰富，熟悉相关技术栈

请回复数字选择候选人
```

### 3. HR选择候选人
```
HR: 1
```

### 4. Bot创建子群 ⭐
```
Bot: ✅ 已选择候选人：张三
     正在创建任务子群...
     
Bot: ✅ 任务子群已创建！
     群名称：T-TASK001-开发登录功能
     成员：HR（你）+ 张三 + Bot
     
     已向张三发送任务通知
     请在子群中跟进任务进度

### 5. 你会收到群邀请
在飞书中，你会看到：
- 📱 新的群聊邀请通知
- 群名称：`T-TASK001-开发登录功能`
- 点击加入群聊

### 6. 在子群中工作
```

- 截止时间: 2026-01-15

有任何问题随时在群里沟通！

## 子群成员

### 初始成员
1. **HR（任务创建者）** - 群主
2. **承接人（候选人）** - 成员
3. **Bot** - 成员

- HR可以管理群成员
- 承接人可以提交任务
- Bot可以发送通知和提醒

## 技术实现

### 代码位置
```python
# app/services/feishu.py
class FeishuService:
    async def create_task_group(self, task_id, task_title, hr_user_id, assignee_user_id):
        """创建任务子群"""
        # 1. 构建群名称
        group_name = f"T-{task_id}-{task_title}"
        
        # 2. 创建群聊
        chat_id = await self.create_chat(
            name=group_name,
            description=f"任务{task_id}的专属沟通群",
            user_ids=[hr_user_id, assignee_user_id]
        )
        
        # 3. 发送欢迎消息
        await self.send_message(chat_id, welcome_message)
        
        return chat_id
```

## 为什么看不到子群？

### 可能原因1：权限不足
**问题**：Bot没有创建群聊的权限

**解决方法**：
1. 进入飞书开放平台
2. 应用管理 → 权限管理
3. 确保已添加权限：
   - `im:chat:write` - 创建群组
   - `im:chat.member:write` - 管理群成员
4. 重新申请权限并通过审批

### 可能原因2：测试环境
**问题**：E2E测试只是模拟，不会真正创建群

**解决方法**：
1. 确保服务已启动：`python3 main.py`
2. 在飞书中真实操作：
   - 添加Bot到群聊
   - 发送 `/newtask` 命令
   - 完成任务创建流程
   - 选择候选人

### 可能原因3：配置错误
**问题**：Webhook未配置或配置错误

**解决方法**：
1. 检查事件订阅配置
2. 确保Webhook URL可访问
3. 查看服务日志：`tail -f app.log`

### 可能原因4：候选人user_id错误
**问题**：候选人的user_id不正确

**解决方法**：
1. 在多维表格中检查候选人的user_id
2. 确保user_id格式正确（通常是 `ou_xxxxx`）
3. 可以通过飞书API获取正确的user_id
