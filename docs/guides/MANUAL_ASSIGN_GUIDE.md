# 任务分配功能使用指南

## 功能概述

系统提供两种任务分配方式：
1. **AI推荐分配** - 创建新任务时，AI自动推荐最佳候选人，点击即可分配
2. **手动分配** - 使用 `/assign` 命令手动选择任务和候选人进行分配

两种方式都会自动：
- 更新任务状态为 `assigned`（已分配）
- 创建任务协作群
- 发送通知给相关人员

---

## 方式一：AI推荐分配（推荐）

### 使用步骤

#### 1. 创建新任务
在飞书聊天中发送：
```
@bot 新任务 [任务描述]
```

#### 2. AI分析和推荐
系统会自动：
- 分析任务需求
- 生成任务记录
- 推荐前3名最佳候选人
- 显示匹配理由

#### 3. 一键分配
点击候选人卡片上的 **"✅ 分配给候选人X"** 按钮

#### 4. 自动完成
系统自动：
- 更新任务状态为 `assigned`
- 创建任务协作群
- 在群中发送任务详情
- 通知HR和候选人

### 示例
```
用户: @bot 新任务 开发用户登录功能
系统: [AI分析任务...]
系统: [显示推荐候选人卡片]
      候选人1: 张三 - 技能匹配度95%
      候选人2: 李四 - 技能匹配度90%
      候选人3: 王五 - 技能匹配度85%

用户: [点击"分配给候选人1"]
系统: ✅ 任务分配成功！
      已创建协作群并通知候选人
```

---

## 方式二：手动分配

### 1. 查看待分配任务

在飞书聊天中发送命令：
```
/assign
```

系统会显示所有状态为 `pending`（待分配）的任务列表，每个任务显示：
- 紧急程度图标（🚨 紧急 / 🔴 高 / 🟡 普通 / 🟢 低）
- 任务标题
- 任务ID
- 所需技能

### 2. 选择任务

点击任务卡片上的 **"👉 选择任务 X"** 按钮，选择要分配的任务。

### 3. 选择候选人

系统会显示所有可用候选人列表，每个候选人显示：
- 姓名
- 技能列表
- 工作经验

### 4. 确认分配

点击 **"✅ 分配给 [候选人姓名]"** 按钮确认分配。

### 5. 完成分配

系统会自动：
1. 更新任务状态为 `assigned`（已分配）
2. 在任务记录中标记分配的候选人
3. 创建任务协作群（包含HR、候选人和机器人）
4. 在协作群中发送任务通知
5. 向HR发送分配成功确认消息

## 功能对比

| 特性 | AI推荐分配 | 手动分配 |
|------|-----------|---------|
| 触发方式 | 创建新任务时自动 | 使用 `/assign` 命令 |
| 候选人推荐 | AI智能推荐Top3 | 显示所有候选人 |
| 匹配理由 | 自动生成 | 需自行判断 |
| 适用场景 | 新任务创建 | 已有任务重新分配 |
| 推荐指数 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

## 共同特性

两种分配方式都会自动完成：

### 1. 任务状态更新
- 任务状态从 `pending` 更新为 `assigned`
- 记录分配的候选人信息
- 保持任务追踪的完整性

### 2. 协作群创建
- 群名格式：`任务协作群-[任务ID前8位]`
- 群成员：HR、被分配的候选人、机器人（如果配置）
- 自动发送任务详情到群中

### 3. 通知机制
- HR收到分配成功确认
- 候选人在协作群中收到任务通知
- 如果群创建失败，候选人会收到私聊通知

## 最佳实践

### 推荐使用AI推荐分配
1. **更智能** - AI根据技能匹配度推荐最佳候选人
2. **更快速** - 创建任务后直接点击分配，一步到位
3. **更准确** - 提供详细的匹配理由，帮助决策

### 何时使用手动分配
1. 需要重新分配已有任务
2. 需要查看所有候选人进行对比
3. 对特定候选人有明确要求

## 注意事项

1. **任务筛选**：只显示状态为 `pending` 的任务
2. **候选人数量**：最多显示前10个候选人
3. **任务数量**：最多显示前10个待分配任务
4. **权限要求**：建议仅HR或管理员使用此功能
5. **协作群**：如果群创建失败，任务仍会分配成功，但需要手动联系候选人

## 技术实现

### 相关文件
- `app/webhooks.py` - 命令处理和卡片交互
- `app/bitable.py` - 数据库操作
- `app/services/feishu.py` - 飞书API调用
- `app/services/llm.py` - AI推荐逻辑

### 关键函数
- `handle_new_task_command()` - 处理新任务创建
- `handle_candidate_selection()` - 处理AI推荐的候选人选择（含分配）
- `handle_assign_task_command()` - 处理 /assign 命令
- `handle_assign_confirm()` - 处理手动分配确认
- `update_task()` - 更新任务状态

### 数据格式
任务更新数据：
```python
{
    '任务状态': 'assigned',
    '分配给': [{"id": "candidate_user_id"}]
}
```

## 故障排查

### 问题：看不到待分配任务
- 检查是否有状态为 `pending` 的任务
- 使用 `/tasks` 命令查看所有任务

### 问题：候选人列表为空
- 检查候选人表是否有数据
- 使用 `/candidates` 命令查看候选人列表

### 问题：分配失败
- 检查任务ID是否正确
- 检查候选人ID是否有效
- 查看日志文件 `app.log` 获取详细错误信息

### 问题：协作群创建失败
- 检查机器人权限
- 检查用户ID格式（应为 open_id）
- 任务仍会分配成功，可手动创建群聊
