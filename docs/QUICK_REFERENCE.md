# 快速参考卡片

## 🚀 5分钟上手

### 1️⃣ 添加Bot
群设置 → 群机器人 → 添加「任务管理Bot」

### 2️⃣ 测试连接
```
ping
```

### 3️⃣ 创建任务
```
/newtask
```

### 4️⃣ 选择候选人
```
1  (回复数字)
```

### 5️⃣ 在子群中工作
查看新创建的任务子群

## 🎯 核心流程

```
创建任务 → AI匹配 → 选择候选人 → 创建子群 → 工作沟通 → 提交验收 → 自动归档
   ↓          ↓          ↓           ↓          ↓          ↓          ↓
/newtask   Top-2推荐   回复数字    自动创建    进度更新    /done     7天后
```

## 💬 对话示例

### 创建任务
```
你: /newtask
Bot: 请提供任务标题：
你: 开发登录功能
Bot: 请提供任务描述：
你: 实现JWT认证
Bot: 请提供所需技能：
你: Python, FastAPI
Bot: 请提供截止时间：
你: 2026-01-20
Bot: 请提供紧急程度：
你: high
Bot: ✅ 任务已创建！正在匹配候选人...
```

### 选择候选人
```
Bot: 推荐候选人：
     1. 张三 (92分)
     2. 李四 (85分)
     请回复数字选择

你: 1
Bot: ✅ 任务子群创建成功！
```

### 提交任务
```
你: /done https://github.com/pr/123
Bot: 🔍 检查中...
Bot: ✅ 任务验收通过！
```

## 📊 任务状态

| 状态 | 说明 | 下一步 |
|------|------|--------|
| pending | 待处理 | 等待指派 |
| assigned | 已指派 | 开始工作 |
| in_progress | 进行中 | 继续完成 |
| submitted | 已提交 | 等待验收 |
| completed | 已完成 | 7天后归档 |
| returned | 需返工 | 修复后重新提交 |

## 🔧 故障排查

### Bot没反应
```bash
# 1. 检查服务
ps aux | grep python3

# 2. 查看日志
tail -f app.log

# 3. 重启服务
python3 main.py
```

### 子群没创建
1. 检查权限：`im:chat:write`
2. 检查候选人user_id
3. 查看日志错误

### 简历解析失败
1. 确保PDF是文本格式
2. 文件大小<10MB
3. 手动补充信息
